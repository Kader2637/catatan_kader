Mutasi Data Menggunakan Server Actions

Sebelum Next.js App Router, untuk mengubah data di server dari form sisi client, kita harus membuat API route terpisah (misal: /api/todo) dan memanggilnya dengan fetch request. Server Actions menghilangkan boilerplate tersebut dengan mengizinkan pemanggilan fungsi server langsung dari elemen form HTML.

Mendefinisikan Server Action

Sebuah Server Action dideklarasikan menggunakan direktif "use server"; di baris pertama fungsinya (atau di bagian atas file module terpisah).

Contoh Implementasi Mutasi Form Todo

Berikut adalah contoh component halaman di mana form mengirimkan data input langsung ke fungsi server untuk disimpan, lalu men-trigger re-fetch data halaman secara real-time:

import { revalidatePath } from 'next/cache';

// Database Mock
const todoDatabase: string[] = ["Belajar Next.js", "Konfigurasi Tailwind"];

export default async function TodoPage() {
  
  // Fungsi Server Action untuk menyimpan todo baru
  async function addTodoAction(formData: FormData) {
    "use server"; // Deklarasi mutlak Server Action
    
    const task = formData.get("todoItem") as string;
    if (task && task.trim() !== "") {
      todoDatabase.push(task);
      console.log("Database update:", todoDatabase);
      
      // Bersihkan cache rute ini agar daftar todo terupdate di browser
      revalidatePath("/todo");
    }
  }

  return (
    <div className="p-8 max-w-md mx-auto">
      <h1 className="text-xl font-bold mb-4">Daftar Tugas Anda</h1>
      
      {/* Form Action memanggil fungsi server secara langsung */}
      <form action={addTodoAction} className="flex gap-2 mb-6">
        <input 
          type="text" 
          name="todoItem" 
          placeholder="Tulis tugas baru..." 
          className="flex-1 p-2 border rounded-xl dark:bg-zinc-800"
          required
        />
        <button type="submit" className="px-4 py-2 bg-indigo-600 text-white rounded-xl font-bold">
          Tambah
        </button>
      </form>

      <ul className="space-y-2">
        {todoDatabase.map((todo, idx) => (
          <li key={idx} className="p-3 bg-white dark:bg-zinc-900 border rounded-xl shadow-xs">
            {todo}
          </li>
        ))}
      </ul>
    </div>
  );
}
Kader Note (Progressive Enhancement): Server Actions mendukung Progressive Enhancement secara default. Artinya, elemen form HTML yang diikat dengan Server Action akan tetap dapat mengirimkan data ke server meskipun browser client mematikan JavaScript secara total.
